# VeraSDTool v1.03

Four bootable ProDOS disk images for using the Commander X16 VERA SD card from an Apple II.

## Downloads

- `verasdedit.po` — VeraSDEdit, a 6502 hex sector viewer and editor.
- `verasdformat.po` — VeraSDFormat, a FAT32 formatter and verifier.
- `VeraSD-IFS-ProDOS.po` — installs a resident ProDOS block driver for raw ProDOS SD images. Works with [A2Desktop](https://www.a2desktop.com/) for browsing files on the ProDOS SD volume.
- `VeraSD-IFS-FAT32.po` — standalone FAT32 file client for VERA SD cards.

### Optional SD test images

Unzip the image and select the resulting `.img` in the VERA card configuration. These are SD volumes to mount alongside the corresponding boot disk, not boot disks themselves.

- `VeraSD-IFS-ProDOS.img.zip` — 32 MiB raw ProDOS/A2Desktop test volume for the resident ProDOS driver, with `README.TXT`, `HELLO.TXT`, and a multi-block `MULTI.TXT` sample file.
- `VeraSD-IFS-FAT32.img.zip` — 128 MiB FAT32 fixture containing sample files, including fragmented `HIGH.BIN` and the preallocated `TESTNOW.BIN` used by the write test.

## What's new

- Updated program title screens to **v1.03**.
- Added a ProDOS `STARTUP` menu that detects VERA in slot 2 or 4, initializes the driver and checks SD availability, then offers CATALOG or A2Desktop. The FAT32 boot disk includes a `STARTUP` guide for `FAT32.SYSTEM`.
- Added `VERASD.BIN` alongside `VERASD.SYSTEM` on the ProDOS driver disk. Run `BRUN VERASD.BIN` from Applesoft BASIC to install the driver and return to BASIC. `VERASD.SYSTEM` remains available to ProDOS launchers such as Bitsy Bye.
- Added ProDOS creation and modification dates to files built by the image builders. Base files such as `PRODOS` and `BASIC.SYSTEM` retain their original timestamps.
- Corrected the FAT32 disk volume name to `VERASDIFSFAT32`, using a ProDOS-compatible name without a hyphen.
- Added a FAT32 startup guide and separated the client title, author credit, and main screen with a blank line.

## Tool notes

- **VeraSDEdit:** inspect and edit 512-byte sectors on the VERA SD card.
- **VeraSDFormat:** create and verify a FAT32 volume. Formatting requires explicit confirmation.
- **VeraSD-IFS-ProDOS:** expose a raw ProDOS SD image as a resident ProDOS block device, up to 65,535 blocks (about 32 MiB). `VERASD.SYSTEM` is the SYS launcher entry; `VERASD.BIN` is the Applesoft `BRUN` entry.
- **VeraSD-IFS-FAT32:** catalog root 8.3 names, read files, and overwrite the preallocated `TESTNOW.BIN` test file. This is a standalone client, not a ProDOS FAT32 disk device; file creation, subdirectories, and general FAT32 writes are not implemented.

All four images target a ProDOS-compatible Apple II with a VERA card in slot 2 or 4. FAT32 support remains preliminary.
